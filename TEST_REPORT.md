# v0.4.1 — фактический отчёт

Дата: 14 октября 2026. Исходный main: `9222c3e2d0711cedddeae13d0e1547c52c699cc5`. Ветка `fix/v0.4.1`.

## Воспроизведение исходной ошибки

- Парсер v0.4.0 корректно принимает `8`.
- Полный обычный сценарий в Chromium на **старой демоверсии** (ввести 8 → «Не работает отопление») прошёл. Точная причина сообщённого Android-сбоя в демо не установлена; её нельзя приписывать парсеру или кешу без доказательств.
- На **старом серверном интерфейсе** воспроизведена гонка: при искусственной задержке `/api/config` на 800 мс введённая до ответа комната 8 стиралась пустым `config.room`. Новый UI сохраняет введённую комнату, если сервер её не привязал. Серверно привязанная комната всегда остаётся авторитетной.
